# HeadMath – Kafanla Cevapla! (web / tablet sürümü)

**Oyna:** https://cemyurtlak.github.io/headmath/

Bilim Şenliği için kafa hareketiyle oynanan matematik oyunu. Tablette (Android Chrome), bilgisayarda ve iPad'de tarayıcıdan çalışır.

1. Sayfayı açın, **BAŞLA**'ya dokunun ve kamera iznini verin.
2. **Sınıf seçimi:** Elinizi kendi sınıfınızın kutusunun üzerinde 1,5 saniye tutun (ya da kutuya dokunun).
3. **Cevap:** Başınızı sola eğin, sağa eğin veya zıplayın (ya da şıkka dokunun).
4. Doğru cevapta alkış, yanlışta "zort" sesi çalar. Oyun sonunda isim yazılır, skor tablosu tablette saklanır.

**Tablete uygulama gibi kurmak:** Chrome menüsü → *Ana ekrana ekle*. İlk açılıştan sonra internet olmadan da çalışır.

Ayarlar `ayarlar.js` dosyasındadır (eğim açısı, süreler, puanlar, ses dosyaları).
Python sürümü ve geliştirme kayıtları proje klasöründedir (6NEWTON HEADMATH).
